# MR2 Global Update Project

An initiation package for the migration toward **Ubuntu 24.04, ROS 2 Jazzy, and Gazebo Harmonic**, with development on an Orin Nano and continued operation of the Orin NX rover.

| Read | Purpose |
| --- | --- |
| [English briefing]({{< ref "docs/global-update-project/en/_index.md" >}}) | Project description, execution model, work packages, and kickoff agenda |
| [한국어 안내]({{< ref "docs/global-update-project/ko/_index.md" >}}) | 프로젝트 개요, 개발 절차, 업무 분담, 착수 회의 안건 |

Prepared for SW-team coordination and joint HW/SW integration. This package makes the agenda visible and provides work-item drafts; it does not announce a completed software migration or a rover deployment.

SW 팀 협의와 HW/SW 통합을 위한 착수 자료입니다. 프로젝트 안건과 업무 초안을 공유하며, 소프트웨어 마이그레이션 완료나 로버 배포를 알리는 자료는 아닙니다.
