# 어디서 시작하나요?

마이그레이션 작업을 맡을 때 사용하는 카드입니다. [프로젝트 개요]({{< ref "docs/global-update-project/ko/_index.md" >}}) · [English]({{< ref "docs/global-update-project/en/start.md" >}})

## 알맞은 작업 공간과 환경을 선택합니다

| 항목 | 시작점 |
| --- | --- |
| 후보 소스 | 로컬 `~/mr2-stack-jazzy`, 브랜치 `migration/jazzy`; 작업 전 현재 버전을 확인합니다. |
| 기준 소스 | 조사한 upstream `2026`의 `74422f36…`; 실제 NX 운용 배포 환경은 별도로 목록화합니다. |
| 개발 환경 | 격리된 Humble 또는 Noble/Jazzy 워크스테이션; 셸과 빌드 출력을 분리합니다. |
| 후보 네이티브 시험 | 인수, 환경 구성, 장비 접근을 확보한 뒤 재설정 가능한 Nano에서 수행합니다. |
| NX 로버 | 기존 운용 환경을 유지하고 중단 시험은 협의한 정비 시간에만 수행합니다. |
| 협업 | SW 팀장이 배정하고 통합 담당자가 공통 인터페이스를 검토하며 HW/운용 담당자가 물리 시험 계획에 참여합니다. |

현재 로컬 후보에는 기준 애플리케이션 코드와 마이그레이션 인계 문서가 있습니다. 저장소를 준비했다고 Jazzy 환경 구성이 끝난 것은 아닙니다.

## 지금은 조사와 작업 준비부터 시작할 수 있습니다

아래 명령은 의존성을 설치하거나 장치를 실행하거나 브랜치를 바꾸지 않고 로컬 후보를 확인합니다.

```bash
git -C ~/mr2-stack-jazzy status --short --branch
git -C ~/mr2-stack-jazzy log -1 --oneline
git -C ~/mr2-stack-jazzy submodule status
```

관련 소스·설정과 upstream 마이그레이션 안내를 읽습니다. 입출력 규약을 파악하고 대표 점검 하나를 제안합니다. 리더와 함께 [GU-00부터 GU-12까지의 초안]({{< project-resource "projects/global-update-project/issues.ko.json" >}})에서 관련 작업을 정합니다. 목록화, 소스 조사, 시험 설계, 환경 구성 절차 초안은 물리 시험 시간을 확보하기 전에도 진행할 수 있습니다.

## 구현이나 공유 장비 변경 전에 확인합니다

- 작업 결과, 담당자·검토자, 정확한 기준, 필요한 운용 프로파일, 공통 인터페이스 변경.
- 구성된 환경과 그 공유 설정·주변장치를 관리하는 담당자.
- 필요한 근거와 남은 워크스테이션/Nano/NX 관문.

저장소 위치, 최종 통합 기준, 후보 이미지, 릴리스 기능 선정은 팀이 결정할 사항입니다. 가정을 기록하고 결정의 영향을 받는 작업은 대기 상태로 둡니다. 관련 없는 모든 결정이 끝나야 조사를 시작할 수 있는 것은 아닙니다.

## 검토 가능한 결과를 돌려줍니다

브랜치/SHA와 작은 diff 또는 제안, 환경·의존성·설정 버전, 정확한 재현 명령, 기대·관측 결과, 로그·산출물 manifest, 남은 대상 시험, 다음 행동을 제공합니다. 실행하지 않은 절차는 제안으로 표시합니다. 재현 가능한 설명이 있는 실패도 유용한 근거입니다.

소프트웨어 작업은 명시한 소프트웨어 관문만 닫습니다. 물리 검증이 필요하면 연결된 대기 작업으로 남깁니다. 명시적인 작업 범위가 아니라면 API 포팅과 planner 튜닝, 프로토콜 재설계 등 동작 변경을 분리합니다.

## 누구와 협의할지 구분합니다

Codex에는 범위가 명확한 소스 조사, 수정, 빌드, 시험, 근거 정리를 맡깁니다. 분야 간 규약은 통합 담당자, 공유 Nano 재설정은 장비 담당자, 장치·운동 시험은 HW/운용 담당자, NX 전환은 지정된 릴리스 권한자와 협의합니다.

작업과 인계의 구체적인 형태는 [컨트롤러 로딩 예제]({{< ref "docs/global-update-project/ko/controller-example.md" >}})를 참고합니다. 이미 실행된 패치가 아닌, 제안하는 마이그레이션 실습입니다.
