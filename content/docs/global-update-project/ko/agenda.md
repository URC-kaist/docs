# 착수 회의 안건과 공유 문안

[프로젝트 개요]({{< ref "docs/global-update-project/ko/_index.md" >}}) · [English]({{< ref "docs/global-update-project/en/agenda.md" >}})

이 자료는 프로젝트 설명 검토와 안건 공유를 위한 준비본입니다. 완료된 마이그레이션을 승인받는 대신 협업을 시작하는 것이 목적입니다. 영어를 원문으로 작성하고 한국어로 대응 번역했습니다.

## 요청할 협의

현 SW 팀장 `@yongwhan-chung`을 통해 개발자 배정, 투입 여력, Nano 인수를 조정합니다. HW 통합과 로버 운용 담당자가 물리 시험 요구와 운용 가능 시간을 함께 정하도록 참여를 요청합니다. 이름을 적은 것은 협의 요청 경로의 기록이며, 문서 준비로 알림이나 배정을 보내지는 않았습니다.

## 회의에서 남길 결과

| 안건 | 기록할 결과 |
| --- | --- |
| 목적과 범위 | 첫 릴리스 기능·프로파일, 호환성 확보와 선택적 새 기능 구분 |
| 기준과 소스 | 운용 배포 환경 목록화 계획, 기준 커밋, rover-direct 처리 |
| 하드웨어 | Nano 인수·접근, 정확한 장비 목록, 전용 주변장치, NX 가동 유지 정책 |
| 개발 위치 | 마이그레이션 fork 위치·소유권, upstream 수정 반영, 기준 이슈 위치 |
| 작업 추적 | 공유 Project 소유자·접근, 첫 이슈 배정, 산출물 위치 |
| URC 2027 통합 | 팀 준비 이정표, HW/운용 참여, 잠정 검증 시간 |

실제 날짜, 참여 가능 인원, 작업량 약속은 팀이 기록합니다. 전면 재작성을 제안하려면 별도의 기술 근거를 가져오며, 마이그레이션 착수에 전면 재작성이 필수는 아닙니다.

## 처음 입증할 중간 결과

식별된 기준·범위, 사용 가능한 Nano 시험 장비, 대표 네이티브 smoke 시나리오가 있는 재현 가능한 환경을 만듭니다. 근거를 검토하고 작업량 추정을 갱신한 뒤 분야별 병렬 작업을 확대합니다. 진행 공유에는 재현·검증 가능해진 내용과 다음 결정·시험을 담습니다.

## 공유 문안 제안

> URC 2027 준비를 위한 MR2 글로벌 업데이트 착수 자료를 준비했습니다. Ubuntu 24.04 / ROS 2 Jazzy / Gazebo Harmonic을 목표로 하며, Nano에서 네이티브 개발을 진행하고 운용 중인 NX 로버의 가용성을 유지합니다. 개요와 업무 분담을 검토해 주세요. 착수 회의에서는 기준·범위, Nano 접근, 저장소·Project 소유권, 초기 배정, 공동 HW/SW 검증 계획을 정하고자 합니다. GitHub Project와 저장소 생성은 보류 중이며 현재 산출물은 로컬 초안입니다. 로버 업데이트는 수행하지 않았습니다.

실제 공유 시에는 초안·로컬 설명을 게시된 문서, Project, 저장소 링크로 바꿉니다. 아직 만들지 않은 자원의 가상 URL을 생성된 자원처럼 공유하지 않습니다.
