# 공유 문안 초안 — MR2 글로벌 업데이트

URC 2027 준비를 위한 MR2 글로벌 업데이트 착수 자료를 준비했습니다. Ubuntu 24.04 / ROS 2 Jazzy / Gazebo Harmonic을 목표로 하며, 재설정 가능한 Orin Nano에서 네이티브 개발을 수행하고 운용 중인 NX 로버의 가용성을 유지합니다.

안내 자료는 플랫폼 전환, 병렬 업무, 사람과 자동화의 역할, 공유 작업 추적, 공동 HW/SW 검증을 설명합니다. Project 구성 초안과 이슈 초안을 통해 초기 작업을 배정할 수 있게 준비했습니다. 현재는 로컬 초안이며, 조직 Project, GitHub 마이그레이션 저장소, 이슈는 생성하지 않았습니다.

착수 회의에서 요청할 결과:

- 필수 운용 프로파일, rover-direct를 포함한 통합 기준을 확인합니다.
- SW 팀장 `@yongwhan-chung`을 통해 Nano 인수·접근과 초기 재현성 작업을 조정합니다.
- 마이그레이션 fork와 공유 Project의 소유자·위치를 정합니다.
- HW/운용 참여와 URC 2027 통합 이정표를 조정합니다.

발송 전에 실제 게시된 영문·한국어 문서 링크와 이후 생성한 Project·저장소 URL을 넣습니다. 이 초안으로 메시지를 보내지 않습니다. 로버 업데이트는 수행하지 않았습니다.
